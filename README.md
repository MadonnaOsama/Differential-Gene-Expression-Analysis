# Differential-Gene-Expression-Analysis
Differential gene expression analysis of breast cancer transcriptomic data using Python

## Overview

This project presents a Python-based workflow for differential gene expression analysis using breast cancer transcriptomic data.

## Workflow

* Data preprocessing
* Quality assessment
* Normalization
* Low-expression filtering
* Differential expression analysis
* Multiple testing correction
* Data visualization

## Tools

* Python
* Pandas
* NumPy
* SciPy
* Statsmodels
* Matplotlib
* Seaborn
